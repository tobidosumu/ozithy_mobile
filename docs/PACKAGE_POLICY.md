# Ozithy Flutter package policy

Applies to the Flutter mobile app setup job and every later package choice in the Ozithy Flutter project.

## Requirements

1. **Latest stable only** — When adding any package or dependency, use only the latest stable version. Verify each package’s version on [pub.dev](https://pub.dev) before adding it. Choose the package most suitable for the job at hand.
2. **Widely adopted / battle-tested** — Prefer packages that are standard and widely adopted across notable tech companies and established tech stacks: mature libraries with large communities and proven track records. Do not pick obscure or niche alternatives when a well-known standard exists.
3. **Minimal for scaffold** — Do not add packages beyond what the initial scaffold needs unless required. Any package that *is* added must still meet (1) and (2).
